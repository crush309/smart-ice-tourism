# 多业态融合智慧文旅管控系统 — 设计方案

> 第12届中国研究生智慧城市技术与创意设计大赛·地方特色赛道·赛题3
> 设计日期: 2026-09-15
> 版本: v1.0

---

## 1. 项目概述

构建覆盖哈尔滨冰雪大世界+太阳岛景区的多业态融合智慧文旅管控系统，实现景区运营从"经验驱动"到"数据+AI驱动"的升级，打通景区-酒店-餐饮-旅行社-消费全链路数据，实现从"单一业态运营"向"文旅全场景生态运营"的转型。

## 2. 方案策略

| 决策项 | 选择 | 说明 |
|--------|------|------|
| 整体策略 | 均衡策略 | 全部4个模块写完整架构文档；模块①②做可运行Demo |
| Demo重点 | ①智能运营 + ②智能规划与预判 | 可视化效果最强 + AI技术含量最高 |
| 3D可视化 | Three.js Low-Poly | 视觉效果最佳，数据驱动动画炫酷 |
| AI模型 | 预训练LSTM+微调 | 迁移学习，小样本效果好，学术加分 |
| 核心场景 | 哈尔滨冰雪大世界 + 太阳岛 | 哈尔滨是承办城市，地域优势 |

## 3. 系统架构

### 3.1 四层架构

```
┌─────────────────────────────────────────────────┐
│ 展示层    │ Three.js 3D大屏 + 仪表盘 + 小程序    │
├─────────────────────────────────────────────────┤
│ 业务层    │ ①智能运营 ②智能规划 ③服务优化 ④业态融合│
├─────────────────────────────────────────────────┤
│ 数据层    │ Kafka + Flink + TDengine + MinIO     │
├─────────────────────────────────────────────────┤
│ 感知层    │ IoT传感器 + 摄像头 + 电子围栏 + POS   │
└─────────────────────────────────────────────────┘
```

### 3.2 技术栈

| 层级 | 技术 | 用途 |
|------|------|------|
| 前端3D | Vue3 + Three.js + ECharts | 三维景区可视化大屏 |
| 前端管理 | Vue3 + Element Plus | 管理者仪表盘 |
| 后端业务 | Spring Boot | 业务逻辑、API网关 |
| 后端AI | Python FastAPI + PyTorch | LSTM预测、NLP分析 |
| 实时数据 | Kafka + Flink | 流式数据处理 |
| 存储 | TDengine(时序) + PostgreSQL(业务) + MinIO(对象) | 分层存储 |
| 关系分析 | Neo4j | 游客-消费-业态关系图谱 |

## 4. 核心模块设计

### 4.1 模块① 智能运营（Demo重点）

**功能：**
- IoT数据采集与监控：景区摄像头、电子围栏、WiFi探针数据实时接入
- 电子围栏人流热力图：在地图/3D模型上实时展示各区域人流密度
- 游客画像：年龄、客源地、消费偏好等标签体系
- 旅行社数据整合：入园团队、人数、导游信息管理
- 全场景数据驾驶舱：酒店入住、餐饮就餐、门店消费数据整合

**Demo实现范围：**
- Three.js 冰雪大世界Low-Poly 3D模型
- 实时数据气泡（人流密度、排队时长、热门区域）
- 左右侧数据面板（客流趋势、游客画像、营收概览）
- WebSocket推送仿真数据流

### 4.2 模块② 智能规划与预判（Demo重点）

**功能：**
- LSTM多变量时序预测：输入历史客流+节假日+天气+时段+预售票量
- 客流趋势预判：未来7天每日/每小时客流预测
- 峰值预警：当预测值超过阈值自动告警
- 排队时长预估：基于当前人流推断各项目等待时间
- 资源调度建议：接驳车运力、安保人员配置建议

**AI模型架构：**
```
输入特征(5维) → LSTM编码器(128units) → Attention层 → LSTM解码器(64units) → Dense → 输出预测
```
- 预训练：使用公开旅游数据集（黄山、故宫等）
- 微调：哈尔滨冰雪大世界往年运营数据
- 损失函数：MSE + MAE联合
- 评估指标：RMSE, MAE, MAPE

### 4.3 模块③ 服务智能优化（文档设计）

- 舆情/投诉数据自动采集（OTA平台+社交媒体）
- BERT中文预训练模型进行情感分类
- 服务短板自动识别（关键词提取+聚类）
- 改进建议生成（基于历史案例库）

### 4.4 模块④ 业态融合（文档设计）

- 跨业态数据打通：景区+酒店+餐饮+消费
- 协同过滤推荐：基于游客画像推荐套票组合
- 消费行为分析：RFM模型+关联规则挖掘
- 智能套票设计：组合优化算法
- 定向营销推送：分群策略+优惠券投放

## 5. 数据流

```
IoT设备 → Kafka → Flink实时处理 → TDengine(时序存储)
                                    ↓
                              PostgreSQL(业务数据)
                                    ↓
                              Python AI引擎(预测+分析)
                                    ↓
                              结果回写 → WebSocket推送 → 前端3D大屏
```

## 6. 创新点

1. **Three.js低多边形3D数字孪生**：将冰雪大世界标志性冰建筑以Low-Poly艺术风格呈现，叠加实时运营数据，兼具科技感与艺术性
2. **迁移学习客流预测**：预训练+微调策略，解决寒地景区数据稀缺问题，在学术上具有创新性
3. **多业态知识图谱**：用Neo4j构建游客-景区-酒店-餐饮-消费的关联网络，支持深层次关系挖掘
4. **电子围栏+热力联动**：将电子围栏空间数据与人流密度实时绑定，精确到景区内各冰建区域
5. **冰雪旅游季节性自适应**：模型针对哈尔滨冬季旅游的极端峰谷特征做特殊优化
