## 第4页：痛点分析（引发共鸣）

**四大痛点：**
1. 🔴 **运营盲区**：景区、酒店、餐饮数据各自为政，管理者看不到全局
2. 🔴 **预测靠经验**：客流预测靠"老员工直觉"，节假日经常措手不及
3. 🔴 **服务反馈慢**：游客投诉靠人工处理，问题发现总是在事后
4. 🔴 **业态割裂**：景区、酒店、餐饮各自营销，无法形成合力

**配图建议：** 四个痛点图标 + 数据孤岛示意

## 第6页：系统架构

**展示四层架构图：**
```
展示层 → Three.js 3D大屏 + 仪表盘 + 小程序
业务层 → ①②③④四大模块
数据层 → Kafka + Flink + TDengine + Neo4j
感知层 → IoT传感器 + 摄像头 + 电子围栏
```

**技术栈亮点标注：**
- Three.js Low-Poly 3D | PyTorch LSTM | Neo4j 知识图谱 | Kafka 实时流
